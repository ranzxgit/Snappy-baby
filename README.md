# 📸 Snappy Baby

A modern Korean-style web photobooth built with Vite, TypeScript, HTML, and CSS.

## ✨ Features

- 📷 Live camera preview
- ❤️ Red lighting filter
- 🖼️ Photo strip printing animation
- 🎨 Korean photobooth inspired UI
- 💾 Download photo strips

## 🛠️ Built With

- Vite
- TypeScript
- HTML5
- CSS3

## 🚀 Getting Started

1. Clone the repository and install dependencies

```bash
git clone https://github.com/ranzxgit/Snappy-baby.git
cd Snappy-baby
npm install
```

2. Start the development server

```bash
npm run dev
```

Open the URL printed by Vite (usually `http://localhost:5173`).

3. Build the static site

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
